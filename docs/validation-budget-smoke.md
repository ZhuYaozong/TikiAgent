## 独立真实摘要实验

为覆盖摘要模型另做一次人工构造日志实验：三组旧失败交互加一组近期交互，手动选择保留一组（实验参数，不改变正式默认八组）。没有读取或重跑真实任务。

- `summary` 阶段：low，最大输出8,192 token；实际一次请求。
- 局部内存估算：4,438 → 1,577 token，下降约64.5%。
- 近期完整交互原样保留；旧交互退出码1及测试路径由程序独立保存。
- 摘要仍表明测试失败、尚待修复，没有把 `ok=True` 改写成测试成功。
- SDK 返回 usage.total_tokens=4,402、reasoning_tokens=439；只记录计量，不记录思考正文。

此实验后整批模型计数为65（上限128），普通请求61（上限112）、联网20（上限20）。此前错误模型显示名导致的3次400响应及1次定位请求不属于这份隔离批次账本，也没有因400重试整个 Workflow。
